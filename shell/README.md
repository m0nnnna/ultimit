# Ultimit shell

Quickshell (QML) desktop shell for Ultimit, styled after `docs/design/mockup.html`.

## Run

Inside the Ultimit compositor (needs wlr-layer-shell; GNOME/Mutter will not work):

    compositor/build/ultimit -s "/opt/ultimit/bin/qs -p $PWD/shell"

or `scripts/devbox.sh start` for a headless one to test against.

Headless smoke test: prefix with `WLR_BACKENDS=headless timeout -s INT 15`.
Environment: `ULTIMIT_SKIN=mine|amber|silver|verdant|sakura|paper|void` (also pins the skin against the day/night schedule), `ULTIMIT_FONTSET=hud|neo|clean`, `ULTIMIT_MOTION=0` (static wallpaper).

## Files

- `shell.qml` - entry point; one set of panels per screen (`Variants` over `Quickshell.screens`).
- `Theme.qml` - singleton: tokens for the seven skins (mine, amber, silver, verdant, sakura = dark plum with a hot pink accent, paper = warm light paper with a teal ink accent, void = OLED true black with a cool blue accent; the `light` skins are silver and paper), `fontSet`, `skinAuto` (both below), `skin` property, and `accentOverride`: your own accent on every skin ("" = the skin's own; Settings > Appearance, whose "From wallpaper" button (`apps/settings/WallpaperAccent.qml`) takes the most vivid hue of the picture wallpaper through a Canvas, `qs ipc call accent set <#rrggbb>|reset|get`). The text on the accent turns dark or light by its brightness and `bad` moves to orange for red-ish accents; `accented()` in `theme/gtk/build-gtk.py` applies the same rules to GTK, Discord and fastfetch, and `build-cursors.py` draws it into the cursors.
  Fonts: `fontSet` picks the display / UI / mono families, saved as `fontSet` in shell.json (`qs ipc call fontset set hud|neo|clean|get|list`, `ULTIMIT_FONTSET` for one run). `neo` (default) is Oxanium / Saira / JetBrains Mono, `hud` the original Michroma / Chakra Petch / Share Tech Mono, `clean` Space Grotesk / Inter / JetBrains Mono. The new families are the variable fonts from google/fonts (`assets/fonts/*-VF.ttf`, OFL licences beside them); `build-gtk.py` and `discord.py` follow the set too. The compositor's window titles are still Michroma (compiled into `compositor/src/theme.h`).
  Day/night: `skinAuto` in shell.json, `{"enabled":false,"day":"paper","night":"mine","dayStart":"07:00","nightStart":"19:00"}`. When enabled, `Persist.qml` switches the skin as the clock crosses `dayStart` / `nightStart`, at startup and whenever the schedule is edited (a skin picked by hand holds until the next switch). `qs ipc call skin set <name>|get|list|auto on|off|get`.
- `Config.qml` - singleton: launch commands, app_id match lists, ticker headlines, motion/fps, metrics.
- `qmldir`, `components/qmldir` - register singletons/components.
- `components/Wallpaper.qml` - background-layer window; Canvas port of the mockup's shard/hex/ring drawing (<= 20 fps, once when motion is off); hosts the wordmark.
- `components/Wordmark.qml` - "[ ULTIMIT ]" + caption.
- `components/Rail.qml`, `RailButton.qml` - left rail (exclusive zone 84), launch/focus logic via ToplevelManager.
- `components/Icon.qml`, `Emblem.qml` - Shape/PathSvg ports of the mockup SVG icons and hex emblem.
- `components/StatusBlock.qml` - clock, date, system row (placeholders), bottom layer.
- `components/Ticker.qml` - bottom news ticker (exclusive zone 26, left margin = rail width).
- `Persist.qml` - loads/saves `~/.config/ultimit/shell.json` (skin, skinAuto, fontSet, accent, motion, shardDensity, bootOnStart) via FileView/JsonAdapter and syncs it with Theme/Config. Env vars (`ULTIMIT_SKIN`, `ULTIMIT_MOTION`, `ULTIMIT_BOOT=0`) override the file for that run without being saved.
- `Boot.qml` - boot sequence overlay (overlay layer, per screen); plays at startup unless `Config.bootOnStart` is false, and on `Config.playBoot()` (Accessory button, desktop menu, `qs ipc call boot play`).
- `apps/settings/` - Settings window (FloatingWindow titled "SETTINGS", rail ACCESSORY button): appearance, display (15 s revert, saves `~/.config/ultimit/displays.conf`), sound (`audio.py` lists a graphics card's HDMI/DisplayPort outputs by monitor name from `pw-dump` and switches between them with `wpctl set-profile`; tests: `python3 apps/settings/test_audio.py`), network (with VPNs: `VpnSection.qml` + `vpn.py`; WireGuard .conf / OpenVPN .ovpn import or a pasted WireGuard config, sign-in with the password in the keyring, never autoconnect; tests: `python3 apps/settings/test_vpn.py`), Bluetooth, power/idle, input (`compositor.ini`), default apps, date & time, users (`users.py` lists accounts and changes your own password through `passwd`; other accounts go through `distro/system/usr/libexec/ultimit/users-helper` via pkexec, polkit `org.ultimit.users`; tests: `python3 apps/settings/test_users.py`), updates (`updates.py` reads apt/Flatpak/fwupd state; installing goes through `distro/system/usr/libexec/ultimit/updates-helper` via pkexec, polkit action `org.ultimit.updates`; tests: `python3 apps/settings/test_updates.py`, `UPDATES_FAKE_DIR` for fake data), about. IPC: `qs ipc call settings open <page>|toggle|close`. `ULTIMIT_DRY_RUN=1` logs system changes instead of making them.
- `apps/accessory/` - shared widgets (ChamferButton, ToggleRow, SliderField, SkinCard, SectionLabel).
- `apps/data/` - DATA file manager (FloatingWindow titled "DATA"): `Data.qml` singleton, `DataWindow.qml`, `data.py` stdlib helper (listing, jobs, trash, properties, open-with). Tabs: Ctrl+T new, Ctrl+W close, Ctrl+Shift+T reopen, Ctrl+(Shift+)Tab / Ctrl+PgUp/PgDn switch, Ctrl+Shift+PgUp/PgDn move, Ctrl+1..9; middle-click a folder, archive, sidebar place or path segment to open it in a background tab, middle-click a tab to close it, drag tabs to reorder, drop files on a tab to move them there. Opening a path while DATA is showing opens a new tab. Typing in the address bar lists matching folders/files under it (Tab completes, then cycles; Up/Down pick). Dragging files out of the window hands them to the system drag (text/uri-list, copy) for other apps. "Show in folder" from browsers and other apps comes in through `session/ultimit-filemanager1` (org.freedesktop.FileManager1). IPC: `qs ipc call data open <path>|reveal <file>|newtab <path>|toggle|close`; CLI `bin/ultimit-data [--reveal] [path]`. Env: `ULTIMIT_DATA_START`, `ULTIMIT_DRY_RUN=1`, `ULTIMIT_FAKE_LSBLK=<file>`.
- `apps/clipboard/` - clipboard history (Super+V, `bin/ultimit-clipboard`): `clip.py watch` runs under the shell for the session (`wl-paste --watch`), keeping the newest 50 texts/PNGs plus pinned ones in `~/.local/share/ultimit/clipboard/` (secrets marked by password managers are skipped; a new login keeps only pinned). `ClipboardPanel.qml` (overlay, bottom-right): Enter pastes into the previous window (wtype Ctrl+V, Ctrl+Shift+V for terminals), P pins, Del removes. IPC: `qs ipc call clipboard toggle|open|close|list`. Tests: `python3 apps/clipboard/test_clip.py`.
- `apps/store/` - STORE (own process, `store-shell.qml`; `bin/ultimit-store [--search WORDS | --app ID | --installed]`): app store over Flathub. `store.py` indexes the AppStream data flatpak keeps on disk (cached in `~/.cache/ultimit/store/`) for picks, categories, search and app pages; install/remove are queued `flatpak` runs (system installation, polkit asks), and STORE stays running until they finish. The rail's not-installed MAILER/NEWS/AUDIO and uninstalled pins open STORE on a search. IPC: `qs -p shell/store-shell.qml ipc call store open|search <w>|app <id>|installed|install <id>|dump`. Tests: `python3 apps/store/test_store.py`.
- `apps/image/` - IMAGE, the image viewer (own process, `image-shell.qml`; `bin/ultimit-image [FILE...|DIR]`), the default for pictures (the session sets it once per user for every picture type left unset or on imv). One file opens with the others in its folder to step through (DATA's name order, `image.py list`); several files open as one set. Started without a file (or on a folder) it shows the library (`Gallery.qml`, `image.py dir`): the folder's pictures as thumbnails (newest first or by name, S switches), its picture folders as tiles with their newest picture as the cover, and Places (Pictures, Screenshots, Wallpapers, Downloads, Desktop, the ones that exist); Enter or a click opens a picture, and Esc, G or Grid goes back to the grid (Backspace/Alt+Up: the folder above, F5: reload). Fit / 1:1 / wheel zoom around the pointer, drag to pan, double-click toggles fit and 1:1, rotate (view only), GIF/WebP animation, Wallpaper, Show in folder, Copy (wl-copy), Delete (to DATA's Trash). Keys: Left/Right/Space/Backspace, Home/End, + - 0 1, R / Shift+R, Ctrl+C, Delete, K pause, Tab hides the bars, Esc closes (back to the grid when there is one), Q/Ctrl+W closes; Super+F for fullscreen. Formats: Qt's own plus qt6-image-formats-plugins and kimageformat6-plugins (AVIF, HEIF, JPEG XL, PSD...). IPC: `qs -p shell/image-shell.qml ipc call image open <path>|openset <paths, one per line>|gallery <dir, "" for Pictures>|state`. Tests: `python3 apps/image/test_image.py`.
- `apps/claude/` - CLAUDE, the Claude app (own process, `claude-shell.qml`; `bin/ultimit-claude [--troubleshoot | FOLDER]`; Settings > About > "Troubleshoot with Claude"). Runs on the official Claude Code CLI (`claude -p` with stream-json in and out, `--permission-prompt-tool stdio`), installing it per user with Anthropic's installer when missing. Accounts: each is its own `CLAUDE_CONFIG_DIR` under `~/.local/share/ultimit/claude/accounts/` (or the usual `~/.claude`), signed in with `claude auth login` (the browser hands the login back, or a pasted code); CLAUDE never stores a credential, and every `ANTHROPIC_*`/`CLAUDE_*` variable is dropped from the environment so an account only ever means its own login. Projects: a folder, account, model, permission mode and notes (sent with every chat); "This PC" is built in for troubleshooting, with a system summary (`claude.py sysinfo`: Ultimit version, GPU and driver, monitors, failed services, session log tail, journal errors) attached to its first message. Chats are listed per project and resume their Claude Code session; tool runs show inline and permission asks are answered in the window (Allow / Always / Deny). Data: `~/.local/share/ultimit/claude/` (accounts.json, projects.json, chats/). IPC: `qs -p shell/claude-shell.qml ipc call claude open|troubleshoot|project <id>|folder <path>|state`. Tests: `python3 apps/claude/test_claude.py` (against `fixtures/fake-claude`).
- `apps/ember/` - EMBER, the desktop assistant (own process, `ember-shell.qml`; `bin/ultimit-ember [TEXT]`): Ember, a prim and proper looking (and bratty, tsundere-acting) anime girl drawn as animated ASCII line art (`EmberArt.mjs` builds each frame from a mirrored portrait plus eyes, mouth, bow and swaying hair; `EmberFace.qml` animates it by mood: idle glances and blinks, thinking, speaking, working, asking, happy, error). Plug in any AI (Settings in the window): Claude through Anthropic's Messages API (default `claude-opus-5-5`, effort, server-side refusal fallback), or anything OpenAI-compatible - OpenAI, xAI Grok, a local server (Ollama, LM Studio, llama.cpp) or a custom endpoint; the model list comes from the provider. `ember.py` keeps one neutral history per chat and turns it into each provider's shape on every request (Claude's own turns, thinking blocks included, go back unchanged), so a chat can switch provider midway. Her personality is `persona.md`, sent to every provider so she is the same whatever model runs her; `~/.config/ultimit/ember-persona.md` replaces it. Tools: run_command, read_file, write_file, list_dir, find_apps, launch_app, open, windows, window (focus/minimize/maximize/fullscreen/close via `ultimitctl`), web_search (DuckDuckGo), web_fetch, clipboard_read/write. Commands, file writes and closing a window wait for Allow / Allow for this chat / Deny unless "Let Ember act without asking" is on. API keys go to the login keyring (libsecret; a 0600 file when there is none; `ANTHROPIC_API_KEY`/`OPENAI_API_KEY`/`XAI_API_KEY` are used when nothing is stored). Data: `~/.config/ultimit/ember.json`, `~/.local/share/ultimit/ember/chats/`. IPC: `qs -p shell/ember-shell.qml ipc call ember open|ask <text>|state`. Tests: `python3 apps/ember/test_ember.py` (mock API server and `EMBER_FAKE=1`).
- `apps/firewall/` - FIREWALL (own process, `firewall-shell.qml`; `bin/ultimit-firewall [--blocked]`): ufw on/off, presets that open an app's ports to the home network only (VTube Studio, iFacialMocap/VBridger, VMC, Steam Remote Play, Sunshine, OBS remote, KDE Connect, LocalSend, SSH), the connections ufw blocked in the last 30 min (one click to allow), and every rule. `firewall.py` parses and decides; the root part is `distro/system/usr/libexec/ultimit/firewall-helper` (pkexec, polkit action `org.ultimit.firewall`; reading needs no password for admins, changes ask). IPC: `qs -p shell/firewall-shell.qml ipc call firewall open|blocked|dump`. `FIREWALL_FAKE=1` + `fixtures/make-state.sh` runs it against a fake ufw; tests: `python3 apps/firewall/test_firewall.py`.
- `apps/disks/` - DISKS (own process, `disks-shell.qml`; `bin/ultimit-disks [--usage [PATH]]`): a disks manager (drives, partition bar with free gaps, SMART health, mount/unmount, eject/power off, format) and a disk-usage checker (what takes space, with breadcrumbs, largest files and Move to trash). `disks.py` talks to UDisks2 over the system D-Bus with `gi.repository.Gio` (polkit prompts come from the desktop's agent; a dismissed prompt is `cancelled`); the D-Bus-to-JSON step is a pure function over a GetManagedObjects dict, tested with `fixtures/`. The scanner walks one filesystem, counts allocated blocks, dedupes hardlinks and caches results under `$XDG_RUNTIME_DIR/ultimit-disks/`. IPC: `qs -p shell/disks-shell.qml ipc call disks open|usage PATH|dump`. `DISKS_FAKE=1` shows a fake set of drives whose actions all succeed; tests: `python3 -m unittest apps/disks/test_disks.py`.
- `apps/tasks/` - TASKS (own process, `tasks-shell.qml`; `bin/ultimit-tasks [--performance]`): the task manager, in place of htop. PROCESSES: name (with the window title), PID, user, CPU, memory, GPU memory, threads and state; click a column to sort, search by name/command/PID, Apps / Mine / All, End / Kill / Pause (right-click has the same plus Copy command line). Another user's process asks for the password through `pkexec kill` (a dismissed prompt is `cancelled`); PID 1, the compositor and the desktop shell ask for a warning confirmation first. PERFORMANCE: the last 60 s of CPU (with a bar per core), memory, swap, GPU (NVIDIA through `nvidia-smi`, else AMD/Intel sysfs), disk and network. `tasks.py watch` is one long-running stdlib-only process printing a JSON line per second (CPU needs deltas, so it keeps the previous sample); the /proc parsers are pure functions over text, tested with `fixtures/proc`. The compositor's window list has no PID, so windows are matched to processes by app id (and title when several qs processes share `org.quickshell`); only the main process of an app gets the window, and no window is given on an ambiguous match. IPC: `qs -p shell/tasks-shell.qml ipc call tasks open|performance|dump`. `tasks.py glance [secs]` prints a lighter line (cpu, mem, gpu, vram, net rates) for the desktop's status graphs. `TASKS_FAKE=1` shows a pretend computer whose signals do nothing; tests: `python3 -m unittest apps/tasks/test_tasks.py`.
- `apps/items/` - ITEMS (own process, `items-shell.qml`; `bin/ultimit-items`): settings for mice and other peripherals that keep their own settings. One driver per device in `apps/items/drivers/` (ID, NAME, KIND, VID/PID, `schema()`, `default_config()`, `build(config)` that checks and encodes, `apply(config, fake_out)`), listed in `drivers/__init__.py`; `drivers/hid.py` has the shared key names and hidraw feature-report helpers. First driver: Redragon M990 (04d9:fc41) - 5 profiles of lighting effect/colour/brightness, 5 DPI levels and all 23 buttons as keys, key combinations or mouse functions; Apply rewrites the whole settings memory (176 feature reports, `redragon_m990.template` patched). The mouse can't report its settings, so `~/.config/ultimit/items/ID.json` is the source of truth. Device access comes from `distro/system/usr/lib/udev/rules.d/72-ultimit-items.rules` (uaccess). IPC: `qs -p shell/items-shell.qml ipc call items open|dump|apply`. `ITEMS_FAKE=1` shows every device as plugged in and writes the packets to a file; tests: `python3 apps/items/test_items.py`.
- `apps/discord/` - Discord with Vencord: Vesktop (Flathub `dev.vencord.Vesktop`, in `distro/flatpaks.txt`) with one instance per account, so several accounts are signed in at once. `discord.py` (`bin/ultimit-discord list|setup|open ID|add [NAME]|rename ID NAME|remove ID|theme`) keeps the accounts in `~/.config/ultimit/discord.json` (Discord, Discord 2, Discord 3 by default), starts each with Electron's `--user-data-dir` (`~/.var/app/dev.vencord.Vesktop/config/vesktop-ID`; account 1 keeps Vesktop's own dir and the discord:// links) and writes a launcher entry per account (account 1's overrides the Flatpak's). New accounts start with the system title bar, no first-launch tour and the `ultimit.css` Vencord theme, generated from the skin's palette in `theme/gtk/build-gtk.py` at login, on every start and on a skin switch. Settings > Discord adds, renames, opens and removes accounts. Tests: `python3 apps/discord/test_discord.py`.
- HUD effects (Settings > Appearance > Effects; every one stops with reduced motion / `ULTIMIT_MOTION=0` and while a fullscreen window is focused or on screen):
  - Edge glow: `components/GlowFrame.qml` (soft accent strokes on a panel's border, optional slow travelling light) on the rail, flyouts, launcher, Alt-Tab and notification cards/toasts. `Config.edgeGlow` off|still|travel. Travelling frames share one 25 Hz clock (`Fx.qml`) that runs only while one is visible.
  - Motion: flyouts unfold from the tray icon (scale, 180 ms), `components/DecodeText.qml` scrambles panel titles for ~150 ms (`Config.decodeText`), the rail's active-window marker slides between pins.
  - Reactive shards (`Config.reactPointer|reactAudio|reactWorkspace`, shell.json `wallpaperReact`): the pointer brightens the shards at its bearing, audio pulses them with the default sink's PipeWire peak (`AudioLevel.qml`, a `PwNodePeakMonitor` that exists only while a wallpaper asks), a shift kicks the sweep. Computed on the existing shard step, no extra timer. Ultimit has no workspaces, so "workspace" means the active window changed. The audio peak needs a running PipeWire and was not exercised in the headless test.
  - Status block: `Config.statusStyle` classic|graph. Graph shows CPU / GPU sparklines (`components/Spark.qml`), a RAM `components/SegBar.qml` and NET rates, from `SysStats.qml`, which runs `apps/tasks/tasks.py glance 1` (one JSON line a second, GPU through nvidia-smi every 2 s) only while shown. `Config.clockRing` adds a 60-segment seconds ring.
  - App icons: `components/IconBadge.qml` - in "letters" mode a hex badge, otherwise the chamfer square - used by the rail pins, launcher, WINDOWS list and Alt-Tab.
  - UI sounds: `UiSounds.qml` plays `assets/sounds/*.wav` (made by `assets/sounds/make-sounds.py`, stdlib only, quiet) with pw-play or paplay for flyout, launcher, notification, lock, unlock. `Config.uiSounds` (default off), `uiSoundVolume`; never while a fullscreen window is focused.
  - Theme tokens: `Theme.space(n)` (n x 4 px), `Theme.size.xs..xl`, `Theme.tnum` (tabular digits).
- Wallpaper: `Config.wallpaper` ("" = generative shards, else an image) and `wallpaperFit` (fill|fit|stretch|center), saved in shell.json; picked in Settings > Appearance (picture folders, Browse… via zenity), from DATA's "Set as wallpaper", `bin/ultimit-wallpaper FILE [fit] | --shards` or `qs ipc call wallpaper set <file> <fit>|shards|get`. A missing file falls back to the shards.
- Photo frames: pictures left on the desktop (`Frames.qml` singleton, `components/PhotoFrame.qml`, drawn by Wallpaper on the background layer under every window), saved in shell.json `frames` per screen. Add from the desktop menu ("Add photo frame…", zenity), DATA's "Put on desktop in a frame", IMAGE's Frame button, `bin/ultimit-frame FILE [screen] | --list | --lock ID | --unlock ID | --remove ID` or `qs ipc call frames add <file> [screen]|list|lock <id>|unlock <id>|remove <id>`. Drag to move, the bottom-right grip resizes (keeps the picture's shape), right-click: Lock in place, Open in IMAGE, Change picture…, Remove frame; double-click opens IMAGE.
- `bin/ultimit-screenshot` - screenshots (area/full) and screen recordings (`record-area` Super+Shift+R, `record-full` Super+Alt+R; the same key stops; `stop`, `status`): wf-recorder, H.264 via VA-API on the Intel/AMD GPU with a CPU fallback, plus the sound the PC plays; saved to ~/Videos/Recordings.
- `components/Privacy.qml` - markers in the bottom bar (StatusTray) while something uses the microphone (PipeWire capture streams), the camera (/dev/video* held open) or shares the screen (the portal's screen-cast stream), and REC with a timer while recording (click to stop).
- `components/ShortcutSheet.qml` - every keyboard shortcut on one screen (Super+/, Settings > Input, `bin/ultimit-shortcuts`, `qs ipc call shortcuts toggle`), read live from `ultimitctl keys`; typing filters.
- `Toasts.qml` - singleton toast queue (`Toasts.show(title, msg, command?)`); `components/ToastOverlay.qml` renders it top-right.
- `components/Launcher.qml` - app launcher (rail emblem; `qs ipc call launcher toggle|open|close`): DesktopEntries search, power row with two-step confirm.
- `components/WindowList.qml`, `WindowPopups.qml`, `WindowUi.qml` - rail "WINDOWS" list of every toplevel (click minimize/activate, middle close, right menu, hover tooltip). IPC: `qs ipc call toasts notify "Title" "Msg"` (`show` is shadowed by the `qs ipc show` subcommand, so use `notify`).
- `components/ContextMenu.qml` - desktop right-click menu (opened by Wallpaper).
- `Config.apps[].tryCmds` - ordered candidate commands, probed once at startup; unavailable apps dim in the rail and toast an install hint.
