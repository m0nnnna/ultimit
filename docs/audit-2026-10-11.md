## 2. Findings per area

### 1. Hardware and peripherals
- **Display** - `shell/apps/settings/DisplayPage.qml` (360 lines): resolution, refresh, scale options `[1, 1.25, 1.5, 2]` (line 272), VRR toggle (278), position relative to first output (left/right/above/below, 292), 15 s revert dialog (338). Compositor: wlr-output-management, `output.c:75` VRR auto for fullscreen games. Missing: mirroring, transform/rotation UI (compositor supports `conf.transform`, output.c:180), arbitrary scale (125%/175%), primary monitor, hot-plug layout memory per monitor set, DDC brightness for external monitors. A Windows user plugging in a projector will not find "Duplicate".
- **Night light** - no match for gammastep/wlsunset/redshift in code or `dpkg -l`; `main.c:177` creates wlr_gamma_control manager so a client would work. Windows users expect "Night light" in quick settings.
- **Brightness keys** - `input.c:453-454` -> `shell/bin/ultimit-media` using logind SetBrightness on /sys/class/backlight. Works for laptop panel only. No auto-brightness although iio-sensor-proxy is installed.
- **Audio** - SoundPage.qml: output/input device lists, volumes, mute, per-application streams (line 99-121); QS has output/input sliders and MPRIS now-playing; media keys `input.c:449-458`. `wpctl status` live: PipeWire 1.6.2 OK, Built-in Analog sink + HDA NVidia present. Gaps: no output profile choice (HDMI/analog) beyond sink list, no per-app output routing, no mic-in-use indicator.
- **Bluetooth** - BluetoothPage.qml + `bin/ultimit-agents` pairing agent; `bluetoothctl show`: powered, pairable; a Surface Duo 2 is paired (nmcli shows its BT network). Roadmap says phone pairing tested; A2DP headset flow not recorded.
- **Printers** - `lpstat -p -d`: "No destinations added". Two CUPS stacks run simultaneously: apt `cupsd -l` (pid 228594) AND snap `cups` 2.4.19 (`/snap/cups/1262`, cupsd + cups-browse + cups-proxyd). Roadmap admits "Printing untested". No Settings entry launching `system-config-printer`; it appears only as a normal app in the launcher. A Windows user: "Add printer" is a settings page, here it is a hidden app. No scanner UI (sane-utils present, simple-scan absent).
- **Removable drives/MTP** - `shell/apps/data/data.py` (mtp, mtp-mount, udisks, trash) and `which go-mtpfs` = /usr/bin/go-mtpfs. Roadmap: phone over MTP tested. Phone-as-camera (PTP) and Android file transfer prompts rely on this; fine.
- **Touchpad** - InputPage: tap, natural scroll, disable-while-typing (warns it breaks the ELAN pad), pointer speed, left-handed. No two-finger right-click/click-method setting, no gestures: `grep pointer_gestures|swipe|pinch` in compositor/src = no hits. No 3/4-finger swipe for desktops/overview (Windows precision touchpad users miss these). Log shows libinput "event processing lagging by 67ms" (session.log).
- **Keyboard layouts/IME** - config.c builds a single xkb map (`layout`, `variant`, `options`); `~/.config/ultimit/compositor.ini` has `layout = us`. No layout switcher key (Win+Space / Alt+Shift), no per-layout indicator in the rail. `grep text_input|input_method` in compositor = no hits, so IBus/Fcitx cannot work on Wayland natively; `dpkg`: ibus installed, fcitx5 absent; `ps`: no ibus-daemon. Fonts: `fonts-noto-cjk` and `fonts-noto-color-emoji` installed. Non-Latin text input is therefore impossible except via X11/Xwayland ibus hacks (GTK_IM_MODULE unset).
- **Privacy indicators** - nothing for camera/mic/screencast (`grep camera|privacy` only in icon templates). Webcam exists ("HD User Facing" v4l2 in wpctl). Windows shows tray icons and a hardware kill-key prompt; Ultimit shows nothing when Chromium opens the mic.
- **Game controllers** - `/dev/input/js*` absent (no pad plugged); no controller settings page; relies on Steam Input. Games app (`apps/games`) only manages launch options.

### 2. Power
- Present: `LockScreen.qml:139-166` idle monitors (dim 300 s, lock 360 s, suspend 900 s battery-only; `Config.qml:50-53`); lock on PrepareForSleep (logind inhibitor, LockScreen.qml:194-221); Settings > Power (battery health, profile, idle timings, lid action, PowerPage.qml:102-105); `powerprofilesctl`: performance/balanced/power-saver exist (live value: performance, the power-profiles-daemon default on AC may drain battery on unplug; no auto-switch). logind lid: `HandleLidSwitch` = "suspend". Battery: upower BAT1 100%, charge cycles 3.
- **Missing: low-battery warning and critical action.** `grep -i 'warningLevel|low battery|critical'` over the shell only matches notification urgency (Notifs.qml). Rail colours change at 20%/10% (StatusTray.qml:31-32) and the lock screen turns red at 15% (LockSurface.qml:214), but there is no toast and no automatic hibernate/shutdown; only UPower's own configured action (not checked; see /etc/UPower/UPower.conf) could act, and hibernate is unavailable here. Windows users get a warning at 20/10% and sleep at 5%.
- **Hibernate:** `CanHibernate` = "no"; `/swap.img` is 4 GB (RAM 6.8 GB) and no `resume=`. The QS power menu only has Suspend/Restart/Shut down (QuickSettings.qml:543-553): no Log out, no Hibernate, no Sleep-vs-Lock choice, no confirmation (one click powers off). Ctrl+Alt+Backspace kills the compositor with no warning (input.c:470).
- No "power button / lid close on AC" separate actions (only one lid setting). No battery saver auto-mode, no dim-on-battery-only timings.

### 3. Session and security
- **Lock screen:** Present (ext-session-lock + PAM `ultimit-lock`; `/etc/pam.d/ultimit-lock` includes common-auth). No fingerprint (fprintd not installed; not checked for hardware).
- **Keyring after autologin:** `/etc/greetd/config.toml` has an `[initial_session]` for mino, so no password is typed and `pam_oo7` (session optional, auto_start) cannot unlock the collection. Currently `Locked` = false on `/org/freedesktop/secrets/aliases/default` (the user probably unlocked it via prompt earlier). Also found **10 `oo7-daemon` processes** (pids 4388, 85065, 92681, 104033, 117523, 123621, 138154, 144422, 157987, 177132) - one per session restart; `ultimit-secrets` does `exec oo7-daemon --replace` but old ones are not exiting. And 8 stale logind sessions on tty7 (`loginctl list-sessions`, all `no` active) left behind by restart-session. Roadmap line 38 lists the Secret portal for Flatpak as unchecked: Chromium is a Flatpak, so its "Chrome Safe Storage" key cannot use the Secret portal -> saved passwords/cookies encrypted with a basic key (weaker) and may prompt.
- **Polkit:** Polkit.qml (apps/polkit) agent present; but `Polkit.qml:47` hardcodes identities `mino` and `root`. Any other user would see the wrong account list. pkexec exists.
- **Screen sharing:** `session/portals/ultimit-portals.conf` maps ScreenCast/Screenshot to wlr. xdg-desktop-portal-wlr is running (pid 177254). No `~/.config/xdg-desktop-portal-wlr/config`; chooser defaults to slurp-based output pick. The compositor exports only wlr-screencopy and export-dmabuf (main.c:175-176); no ext-image-copy-capture / foreign-toplevel-export, so window sharing (Teams/Zoom/Discord "share a window") will not work: whole monitor only.
- **Screenshots:** `Super+Shift+S` area, `Print` full (`input.c:505-512`, `bin/ultimit-screenshot`) -> ~/Pictures/Screenshots + clipboard + toast. No delay/window mode, no editor/markup, no Win+PrtSc.
- **Screen recording:** none (`wf-recorder`, `wl-screenrec`, OBS absent). Chromium/OBS would work through the portal once installed, but there is no built-in or documented path.
- **Clipboard history:** wl-clipboard only; cliphist absent; `Win+V` unbound. Compositor does expose data-control (main.c:139).
- **Firewall:** `ufw` installed, service active but `/etc/ufw/ufw.conf` says `ENABLED=no`, i.e. no rules loaded. avahi-daemon and cups-browsed listen on the network. No UI.
- **Updates:** `unattended-upgrades` active, `/etc/apt/apt.conf.d/20auto-upgrades` enabled with security origins. But: no way to see what was installed, whether a reboot is needed, or to apply non-security updates. `update-notifier` is explicitly skipped in autostart (ultimit-autostart SKIP set). `update-manager` is installed but is GNOME/GTK and not wired in. Snap-installed `firmware-updater`, `snap-store`, `desktop-security-center` are present in `snap list` but nothing in Ultimit launches them as a unit; Flatpaks never update automatically. Windows equivalent: Settings > Windows Update. Nothing here.
- **User accounts:** roadmap Phase 3 claims "users" in Settings but there is no Users page (SettingsWindow.qml:19-30 lists only appearance, rail, news, display, sound, network, bluetooth, power, input, defaults, datetime, about). AccountsService not used. Greeter has no user list code to support more than one user was not verified (greeter/Config.qml has no user setup). Changing password, adding a user, avatar: all missing.

Double-click on a video or zip in DATA hands to nothing. DefaultAppsPage.qml (92 lines) lets the user choose per type but needs candidates to exist.
- **Archives:** no file-roller/ark/7z (`dpkg`: unzip, zip present; p7zip, unrar absent). `grep archive|extract|zip data.py` = no hits. Windows right-click > Extract All has no equivalent.
- **Video/music player:** no mpv, vlc, celluloid, ffmpeg (`which` returned nothing). Rhythmbox is the only media app. Chromium (with codecs-extra Flatpak) plays web video only. Local MP4/MKV cannot be opened.
- **App installation:** Flatpak CLI installed with system remote; only Chromium and runtimes installed (`flatpak list`). No GUI: gnome-software is "un" (removed) and nothing replaces it. `Config.qml` "not installed" hints tell the user to `sudo apt install ...` (lines ~118, 126, 135). A Windows user cannot install Steam/Discord/VLC without a terminal. `snapd` is running with snap-store installed (inconsistent with the "snaps-remove" list, which only lists chromium/firefox).
- **Search:** AppSearch.qml ranks DesktopEntries only; no file search (no tracker/localsearch/plocate UI), no calculator or web search in Launcher.
- **Trash:** present (data.py:17-25, freedesktop spec, home trash only; no trash for external drives). Empty-trash is a permanent delete from the UI, fine.
- **Recent files / thumbnails:** no recently-used.xbel handling (`grep recent` none), no thumbnailer (tumbler absent, ffmpegthumbnailer absent), DATA shows icons only.
- **File picker/portals:** portal-gtk handles it (roadmap verified). Drag-and-drop uses the standard Wayland data device; not scripted here.

### 7. Gaming readiness (blockers only)
- Steam: not installed (`dpkg`: steam, steam-launcher, steam-installer none). `x-scheme-handler/steam` has no handler.
- **i386 not enabled:** `dpkg --print-foreign-architectures` printed nothing. Steam, Proton 32-bit titles, Wine, and 32-bit Vulkan (`mesa-vulkan-drivers:i386`, `libnvidia-gl-*:i386`) all need `dpkg --add-architecture i386`.
- NVIDIA: `vulkaninfo --summary` lists GPU0 Intel UHD (Mesa), GPU1 **NVIDIA GeForce GTX 1650 (driver NVIDIA)**, GPU2 llvmpipe; Flatpak has `GL.nvidia-595-99-02`. `nvidia-driver-580` package name is "none" (likely a 595-series packaging; not investigated). Env: no `__NV_PRIME_RENDER_OFFLOAD` globally, but `shell/bin/ultimit-game-run` sets `__NV_PRIME_RENDER_OFFLOAD=1 __GLX_VENDOR_LIBRARY_NAME=nvidia __VK_LAYER_NV_optimus=NVIDIA_only DXVK_FILTER_DEVICE_NAME=NVIDIA` per game and reads `/proc/driver/nvidia`. switcheroo-control is active. Right-click "Launch with dGPU" for non-Steam apps is absent; Chromium runs on Intel unless configured.
- gamemode: installed (`/usr/games/gamemoderun`, gamemoded); MangoHud and gamescope not installed (game-run skips them with a message). Compositor supports tearing control and VRR (main.c:170, output.c:75). Controllers untested.
- Games app (`shell/apps/games`) exists and scans Steam/Lutris/Heroic. Anti-cheat/Proton testing outstanding (roadmap line 69 unchecked).

### 8. Reliability
- **Shell crash:** `session/ultimit-shell` restarts `qs`, with a fall-back to `git archive HEAD shell` into `~/.cache/ultimit/shell-committed` after 2 fast crashes; it exits when the compositor pid (`$XDG_RUNTIME_DIR/ultimit-session.pid`) is gone. Good. Weakness: the fallback needs a `.git` checkout (`git -C $ROOT archive HEAD`), which an installed/ISO tree will not have, and a repeatedly failing shell leaves a black screen with no message.
- **Compositor crash:** `ultimit-session` does `exec compositor -s STARTUP`. When it dies, the whole Wayland session dies with all apps; greetd shows the greeter (initial_session fires only once at boot, so no automatic relogin). No coredump tooling (`coredumpctl` not installed, so crashes leave no trace beyond `session.log`, which only keeps the current + previous session). No "Ultimit crashed, here is the log" dialog.
- **Logs:** `~/.local/state/ultimit/session.log` (+`.old`) contains compositor, shell, PAM output; journald user logs are readable. No log viewer app (gnome-logs removed). Repeated warning: `qt.qpa.services: Failed to register with host portal ... App info not found` (quickshell has no app id; harmless but noisy).
- **Leaks seen live:** 10 oo7-daemon processes and 8 dead logind sessions (above); `ultimit-portal-watch` restarts the document portal every 30 s check if missing (workaround for a real race).
- **First-login-of-new-user:** see ISO blockers. In short, `session/ultimit-session` only works if a user has the repo checkout, the compositor built in `compositor/build/`, and qs/oo7 in `~/.local/ultimit-deps`. On first login `shell.json` and `compositor.ini` have in-code defaults (config.c:37-47, Config.qml) so those are safe. `ultimit-session` copies foot/zathura/imv defaults only if missing (good) and writes gsettings for GTK theme (good).
- **Hardcoded-path audit** (grep of session/, shell/, compositor/src, greeter/, scripts/ for `/home/mino`, `~/code`, `mino`, `.local/ultimit-deps`, `/opt/ultimit`): see ISO list. Code comments only: `shell/Config.qml:110` (`~/code/nekomail`), `scripts/install-system.sh:7`.

## 4. ISO blockers (assume this dev machine)

1. `/usr/local/bin/ultimit-session` (generated by `scripts/install-session.sh`) execs `/home/mino/code/ultimit/session/ultimit-session`; the greetd `initial_session`/user session therefore needs a `~mino` checkout. Needs a system install prefix (e.g. /usr/lib/ultimit) and a dedicated login launcher that works for any user.
