Ultimit 1.1. A new top bar, automatic Game Mode, three new skins and font sets, an animated boot-to-desktop sequence, a full visual polish pass, signed updates and a round of security hardening.

**Updating:** Settings › Updates › Ultimit offers it as usual. Edge PCs (`ultimit-update --edge`) already run all of this. From this release on, updates are signed: a PC only installs a release whose signature checks out against the key it already has.

### The desktop

- **A top bar** on the main display replaces the bottom strip and the desktop clock. On the left, the focused app's name opens its menu (New window, the app's own actions, Fullscreen, Minimize, Close, Quit). In the middle, the news ticker now carries your notifications too. On the right, the tray and the time, which opens a big clock over quick settings. Over a fullscreen window it hides and slides back when the pointer touches the top edge.
- **Pinned rail apps own their windows**, dock-style: click to launch, focus, minimize or cycle through them; middle-click for a new window; right-click lists them. Rail menus and tooltips open beside their button on every screen.
- **Quick settings, rebuilt:** toggle tiles for Wi-Fi, Bluetooth, Do not disturb and Game mode, sliders with mute buttons, a power profile switch, a now-playing card and a row of power buttons (the destructive ones ask for a second click).
- **The focused window glows** in your accent with `[ ]` corner marks that fade with focus. Close and minimize animations can be turned off, and minimize now heads toward the rail.
- **One motion language** across the shell, the apps and the greeter, and a polish pass on every panel, menu and app: cleaner surfaces, real app icons in the launcher and window list, nothing smaller than 12 px. Skin changes crossfade. Reduce motion now covers everything, the lock screen and greeter included.
- **A livelier wallpaper:** the shards react to the pointer, audio and window changes. The status block can show CPU, GPU, RAM and network graphs and a seconds ring.
- **Settings › Appearance › Effects** for glass, glow, sounds and the rest.

### Skins and fonts

- **Three new skins:** Sakura, Paper and Void.
- **Font sets:** HUD, Neo (the new default) and Clean, with a preview of each. Window titles follow them.
- **Day/night skins** switch on a schedule, and **From wallpaper** picks an accent from your wallpaper.
- Flatpak browsers follow a skin change while they're open, and tray icons stay readable on light skins.

### Boot, login and lock

- **A boot splash in the Ultimit look** on every monitor, with a styled password prompt.
- **One animated sequence from power-on to the desktop:** the login screen opens on the splash, logs you in back into the emblem, and the emblem cracks into glass shards that fall away to reveal the desktop.
- **A new lock screen** that sweeps in, idles with slow shards and wipes away on unlock. A wrong password glitches the card.

### Games

- **Automatic Game Mode.** A fullscreen game, or one started from Steam, Proton, Wine, gamescope or GAMES, pauses every shell animation, quiets UI sounds, holds notifications until you're done (critical ones still show) and switches to the performance power profile. Settings › Power › Game Mode; a GAME chip shows when it's on.
- No panel glass is drawn over a fullscreen game, so a toast or the volume OSD costs nothing.

### Security

- **Signed updates.** Every release is signed on GitHub, only with the owner's approval; Settings only offers, and the updater only installs, a signed release that says it is that version.
- **Flatpak apps can no longer** type into other windows, read the screen or clipboard, or draw a fake lock or password prompt. Screen sharing still works through the portal.
- **EMBER asks first** before reading hidden files in your home, and before sending anything out once a chat has read a web page, file or command output.
- A hidden or background window can no longer hold off auto-lock, USB disks don't mount while locked, and the password dialog warns when an app asks to run a shell as root.
- Hardening around the lock screen, the compositor's IPC, Flatpak browser themes and shared folders.

### CLAUDE

- Chats run on Sonnet and call in Opus when stuck, with Haiku for the grunt work: much cheaper for the same results.
- A bar suggests a new chat once a chat's context gets long, and chats can move to another project.

### Fixes

- Ctrl, Super and the other modifiers no longer get stuck after waking from sleep, and all keyboards share one layout and modifier state.
- Desktop animations no longer stay paused after the first unlock, and idle lock works again after it.
- No stray blur box on rotated (portrait) monitors.
- Screenshot and recording shortcuts no longer close open menus, and the OSD and password prompt return to the main display after a menu was open on another.
- No glass halo around browser menus, and no wallpaper strobing at low shard density.
- The boot splash is selected on Ubuntu 26.04, whose plymouth no longer ships `plymouth-set-default-theme`.
- A lighter idle desktop: the wallpaper and rail no longer repaint every monitor at full refresh rate.
