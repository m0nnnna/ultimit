Ultimit 1.2. Full-system backups with BACKUP, a classic mouse cursor with a neko paw, Claude Code and the Claude desktop app side by side, a smoother mouse in captured games, DATA that talks to the rest of the desktop's clipboard, and an install report to send when the installer fails.

**Updating:** Settings › Updates › Ultimit offers it as usual. Edge PCs (`ultimit-update --edge`) already run all of this.

### BACKUP

- **Back up the whole PC** from the new BACKUP app: one click copies the system, apps, settings and boot files, with a live progress bar. Root work goes through a small whitelisted helper that asks for your password; restoring always happens from a rescue USB, never over the running system.
- **Verify a backup** against its checksum with one click, and keep only the newest ones with a retention setting.
- **Schedule it** (nightly, weekly or monthly): the PC backs itself up even when you're not logged in, on a systemd timer.
- **Encrypt backups** with a generated passphrase, and keep the recovery steps (plus the passphrase location) in the Recovery tab for when the disk dies.
- BACKUP lives in the rail and the launcher as its own window (`ultimit-nekoshot`).

### The mouse cursor

- **A classic style joins Izy and Shard** (Settings › Appearance › Mouse cursor): the familiar notched arrow, a white I-beam, plain resize arrows, a circle-and-slash and a ring spinner — white with a dark outline, the way every other OS draws them.
- **The link pointer is a cat's paw**: three toe beans and the big pad, in the skin's accent — and the open paw (grab) shows the full set of four. Beans, badges and the spinner still follow your accent, and changing skin, accent or cursor style recolors the cursor live, no relog needed.
- `qs ipc call cursor set izy|shard|classic | get` switches the style from a script or the terminal.

### Claude Code, and the Claude desktop app beside it

- **The launcher lists both**, unmistakably: "Claude" (Anthropic's desktop app) and "Claude Code" (Ultimit's own app, renamed from "CLAUDE" so the two never shadow each other). Installing the desktop app from Anthropic's repository no longer leaves it invisible.
- **Your keyring stays Ultimit's**: the desktop app pulls in gnome-keyring as a dependency, and its autostart is now skipped so it can no longer take the Secret Service from oo7 on login.

### Games

- **Mouse-look stays smooth and captured**: pointer locks follow keyboard focus, so the cursor can't slip onto another monitor over a panel, and Xwayland games (Proton) no longer stutter while the pointer is locked.
- A Wine window that covers the whole screen is treated as real fullscreen (direct scanout and Game Mode work for it).

### DATA

- **A hung folder no longer stops navigation**: a listing that stalls (unlocked phone, dead network mount) times out and says so, and switching folders kills the stuck listing.
- **Copy and cut publish to the system clipboard**, so files paste into and out of other apps; pasting an image from another app saves it into the folder, and files dropped into DATA from a browser or chat are copied.

### Installer

- **When an install fails, save the report to a USB stick.** The failed screen's button collects the logs, hardware and network details (passwords, Wi-Fi keys and hashes blanked out) and copies the file to any plugged-in USB drive — no more photographing the screen.

### Fixes

- **OpenVPN imports work out of the box** in Settings › Network › VPN (`network-manager-openvpn` now ships; WireGuard already worked).
- **X11 apps keep paste working**: the clipboard is re-announced when an Xwayland window gains focus.
- ITEMS accepts typed symbols (`- = [ ]`, …) as key names again.
- Backup folders with spaces in the path (a USB drive's name) work everywhere, including scheduled backups, and the backup directory is private to root (0700).

### Behind the scenes

- Pushing a version tag now builds the release on GitHub itself, in a clean Ubuntu 26.04 container, and publishes it signed as before — no PC builds the release by hand.
- Every app test suite runs on each push and pull request.
